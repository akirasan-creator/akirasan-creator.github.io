Personal Drive Backup

A private tool used by one person to copy their own files from a local PC to their own Google Drive. It is not offered to anyone else.

個人が自分の PC のファイルを、自分の Google Drive へバックアップするための個人用ツールです。ほかの人には提供していません。

Privacy Policy / プライバシーポリシー

  • Scope: https://www.googleapis.com/auth/drive.file only. The tool can see and change only the files it created itself in the user's own Drive. It cannot read other Drive files.
    権限は drive.file だけです。このツールが自分で作ったファイル以外は読めません。
  • No data is sent to the developer or to any third party. There is no server; everything runs on the user's own PC.
    データを開発者や第三者に送ることはありません。サーバーはなく、すべて利用者の PC で動きます。
  • The OAuth token is stored only on the user's PC. It is not shared, sold or used for advertising.
    認証トークンは利用者の PC にだけ保存され、共有・販売・広告利用はしません。
  • Access can be removed at any time at myaccount.google.com/permissions.
    アクセス許可は上のページからいつでも取り消せます。
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
